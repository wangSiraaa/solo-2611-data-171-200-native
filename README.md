# 工程量纲文本协议
文件是实际待诊断文本，不给AST。`.dims`每非空行是 `name : dimension_product`；dimension_product为1或以空格分隔的M/L/T/Theta，可带有理数幂，如`M L^2 T^-2`或`L^(1/2)`。每变量最多一个声明，重复冲突需定位；缺声明表示未知维数。`.formula`每行 `label : expr = expr`，label唯一。注释#到行末，名称只ASCII标识符；行列位置按解码后Unicode码点计。

语法优先级：括号/函数、字面量幂、前置+/-、乘除、加减。幂仅整数或括号有理数常量，分母正；一元负号低于幂，如-x^2按-(x^2)。函数只有exp/log/sin/cos（输入与输出均无量纲）和sqrt（量纲乘1/2）。加减两侧维数必须相等；乘除维数相加减；等号两侧相等；纯数包括0都是无量纲。表达式不求实际数值，不检查其数值定义域。

量纲向量为M/L/T/Theta四维有理数。跨公式同名变量共用未知向量，循环公式是联立约束而不是执行循环。求解输出已知/唯一推断/参数化自由维数，不能把未约束变量默认为无量纲。矛盾报告以声明和命名公式为source statement单位，给一组包含极小的矛盾集合（删其中任一statement即相容），不要求全局最小数量。可附某基础维数上的线性组合0=c!=0作为代数证据，必须能追到具体源span。

model是主要材料，conflict/function-conflict用于独立追加场景，syntax-bad用于语法拒绝。不要把所有异常场景一起读取掩盖独立原因。不做单位换算、温标偏移、数值求解或自动改公式。

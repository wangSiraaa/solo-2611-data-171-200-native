# 小型肽谱匹配材料
FASTA与MGF均合成，禁止联网检索蛋白。FASTA已分target/decoy，名称不决定某谱的答案。按胰蛋白酶：K/R后切，若下一位是P不切；蛋白两端也是边界。允许0或1个漏切，筛长度4–20。C固定加57.021464，M允许至多一位氧化+15.994915；未氧化也是候选。不同蛋白产生同一序列+同一修饰位置只是一候选，保留全部来源。target/decoy若产生完全相同候选，排除该候选并报告共享，不能让同一化学实体自我竞争。

plan质量单位为Da，前体质量M=残基和+水；m/z=(M+z*proton)/z。b_i=前i个修饰后残基和+proton；y_i=后i个残基和+water+proton，i=1..n-1，碎片只1+。无同位素校正、无中性丢失，I/L等质量不能靠质谱区分。可自行设计公开、确定的碎片匹配评分；每个实验峰/理论离子在一次匹配中最多使用一次，同一m/z重合理论离子须明确处理。候选前体ppm以理论m/z作分母；记录所有并列最佳肽身份。

每谱target和decoy用同一流程竞争，分数相等由decoy获胜。无前体候选或少于plan规定匹配片段要标为未鉴定。对全部合格获胜谱按score降序，以完整同分组为阈值累计T/D，FDR=min(1,(D+1)/max(T,1))；target的q值是包含该谱的所有更宽阈值中最小FDR，不能拆同分组。此小合成集合演示统计口径，不据此保证真实实验FDR。输入中含重复谱内容以核验阈值并列处理。

# 有限关系规则输入
JSON atom 包含 predicate 和 args。以 `?` 开头的非空字符串为变量，其余字符串为常量；不支持匿名变量、函数、算术、比较、聚合、NULL。所有位置均为字符串，谓词元数由 schema 固定；extensional 谓词只能来自输入事实，其他为派生谓词。rule 的 positive/negative 列表均是合取，head 单原子；至少一个 positive。规则变量需在正体出现，头部与负体变量都受此约束。

闭世界的 not 只能在其引用谓词已达到不动点的低层上解释。正递归（包括循环数据与递归谓词自依赖）合法；包含负边的依赖环不合法。同一事实只保存一次，但来源可多条。应基于声明/规则检查全部程序，而不是只检查当前有数据的分支。

基础输入描述 supplier/link 关系，常量 W 是仓库。不要根据名字猜意义，按规则求关系即可。queries.json 只规定需解释的查询，不提供答案。结果应包含各层完成关系、每轮delta大小和实际join候选统计；证明记录 rule id、变量绑定、正前提/来源、已闭合层的负查询缺失。

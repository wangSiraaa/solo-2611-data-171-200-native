# 小反应RXN/SDF材料
真实V2000 RXN含反应物/产物各组件，SDF为同一组组件的独立读回辅助材料，SIDE/MOLECULE_INDEX指认位置。输入atom-map为0，坐标仅排版，不参与对应。只非氢原子、非芳香单/双/三键，最多9个重原子且同元素最多6；支持原子同位素及形式电荷。元素/同位素计数必须守恒，隐式氢和形式电荷可随反应改变，应保留并报告，不据它们硬匹配。

明确教学级目标：在元素/同位素保持的全部反应物到产物重原子双射中，最小化每对重原子的键级差绝对值之和，未成键为0。它定义本题计算答案，不宣称找到了真实反应机理。允许图匹配/数值通用库及RDKit读写，不调用完成的reaction atom mapper。提供一个最优主映射；若存在同值替代，给一份替代并标不唯一即可，不要求导出所有映射。对称原子编号不是额外化学证据。

输出mapped RXN/SDF用1..N的atom-map编号，使两侧每个编号恰出现一次；保持原分子分组、原子/键属性和组件原顺序。change表按映射原子对报告断键/成键/键级变化，原子表报告charge、isotope、显式/隐式H before/after。读回用化学库核对，不仅检查JSON。hydrolysis-permuted是原子编号置换后的独立RXN，无对应SDF；其余同名SDF为辅助对照。nonconserved为可解析但元素不守恒案例。

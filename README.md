# 三维Zarr材料

source.zarr是真实Zarr v2单数组目录（29×37×41，<i4），源chunk为8×13×17、zlib压缩，若干chunk文件缺失。它们按Zarr语义代表fill=-999，不是待修补损坏。边缘chunk完整编码再裁逻辑范围。

plan.json定义轴置换[2,0,1]、目标chunk11×9×10和12288字节数据缓冲。源单块7072字节、目标单块3960字节，整逻辑数组175972字节；因此单块及一对块可装入，但整数组不可用于执行器。实现者须自行确定可满足单次解码/单次写入的外部重组策略。验证阶段可另行全读。

corrupt-chunk.bin是独立的截断压缩块，用plan所述方式在副本替换原块后测试失败；不要改原输入。requirements给出独立消费者与codec依赖，可用zlib自行解码。材料不含目标数组或参考切片计划。
